#+title: Liver Failure Relapse
#+author: Toxidroma

* What's this?
This is an addon for Garry's Mod that implements the vast majority of
the game known as _Liver Failure Relapse_, a surreal horror roleplaying
game that is built off of DarkRP.

DarkRP is modified mostly not by editing its gamemode files
themselves, but a separate modification addon. This is that addon.

However, in developing this project, there were unfortunately changes
that had to be made to DarkRP's core gamemode itself. This is covered
in the below installation instructions.
* How do I install this?
This is a game for Garry's Mod, which itself (or its server) should be
installed. The below instructions assume you know where to find its
primary directory structure.

1. Clone this repository
> ~git clone ssh://death.town:23231/liver-failure-relapse~
2. Move =liver-failure-relapse= into =garrysmod/addons=
The resulting folder name can be anything.
3. Clone =relapse-darkrp=
This is the modified DarkRP core that Liver Failure Relapse requires
in order to function. _It will not work_ using 'vanilla' DarkRP without
serious problems.
4. Move =relapse-darkrp= into =garrysmod/gamemodes=
5. Ensure =relapse-darkrp='s name is =relapse=
That is, you should end up with a path that reads
=garrysmod/gamemodes/relapse=. The gamemode will not load if you do not.
6. Pray
* Dependencies?
Outside of this repository and the modified DarkRP necessary for it to
work, there is some code that Liver Failure Relapse relies on which is
not yet publicly available. If you want to host it at this time and
you're not us, you probably can't just now. This will hopefully change
in the future, and there will be a lot more to play with whenever that happens.

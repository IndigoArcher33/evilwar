**** TODO Commands
- [ ] Chatbox
  Commands here are written in the ingame chatbox. Some of them are prefixes, in
  that they expect text to the right of them, others don't require additional
  input, some might even be able to do both... it depends.
  + [ ] IC [0/3] [0%] :: 'In-character' communications and whatnot.
    * [ ] Speak :: No prefix.
      Speak to those around you with an average volume.

      Speech appears in a blu-ish color.
    * [ ] Yell :: =/yell <words>=, =/y <words>=
      Shout at the top of your lungs, so your lamentations reach further.

      Shouting appears in red and it jitters. It also modifies your text input
      by uppercasing every character possible, and replaces =.= with =!=.
    * [ ] Whisper :: =/whisper <words>=, =/w <words>=
      Quietly transmit your secrets to others.

      Whispering appears in grey and in a smaller font.
      Whispering will never transmit through walls like other forms of speech.

      Unlike other speech commands, whispering will not produce an audible sound ingame.
  + [ ] OOC [0/2] [0%] :: Out-of-character communications.
    These necessarily entail thinking outside of the game's boundaries and
    should not be used too frequently. They should _never_ be used to transmit
    in-character information.
    * [ ] Global :: =// <words>=, =/ooc <words>=
      Send a message to everyone. Useful if you are confused about a game's
      mechanic and can refer to it without shattering the atmosphere.

    * [ ] Local :: =[[ <words>=, =.// <words>= =/looc <words>=
      Send an out-of-character message to people around you.
- [ ] Console
  Commands here are written in the developer console, which is (near)
  universally located on the =~= key.
  + [ ] Commands [0/1]
    These do something and/or print information.
    * [ ] =donations= :: List what donation rewards you have.
  + [ ] Settings [0/2]
    These aren't so much commands, but configurations of your preferences.
    * [ ] =lfr_rainbow_playermodel= :: Toggles playermodel color cycling.
      Requires the ~rainbow~ donation reward.
    * [ ] =lfr_rainbow_physicsgun= :: Toggles playermodel color cycling.
      Requires the ~rainbow~ donation reward.
